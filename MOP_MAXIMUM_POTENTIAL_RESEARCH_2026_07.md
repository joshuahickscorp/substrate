## 1. Decision

The project is not waiting for a larger computer. Its current weighted actionable realization is
5.9 out of 10 across 37 facets. The limiting variables are evidence identity, implementation,
natural and natively synchronized inputs, causal controls, independent units, and confirmation.
The current requirements matrix has no measured hardware blocker and no earned Studio requirement.

The highest-value architectural move is to stop treating any inherited vision encoder as the
platform. An inherited encoder is now only one frozen measuring instrument among several. The
platform is the owned system around it:

1. immutable referent, event, branch, and lifecycle identity;
2. vision, audio, action, telemetry, and environment adapters with explicit clocks;
3. compact object, relation, state, and uncertainty representations;
4. predictive and counterfactual transition models;
5. governed memory and plasticity across several time scales;
6. causal broadcast, self-monitoring, and resource allocation;
7. controlled action, developmental, social, and material simulators;
8. a proof system that can reject its own attractive results;
9. an adaptive host governor that maximizes local throughput without taking control of user work.

The official dense ViT-B runtime is useful because it supplies a local dense-token control and a
teacher-independent comparison surface. It does not determine the eventual topology. The custom
substrate program should learn from the experiments which state variables, recurrence, memory,
factorization, update rules, and interfaces deserve to survive.

## 2. What was absorbed and what changed

The repository contains work produced across several sessions and tools. This integration treats
authorship as irrelevant and receipts as decisive. Every prior checked box was audited at the

The audit found 199 checked boxes. Their primary classes were:

The important correction is semantic. A checked test, class smoke, preflight, memory probe, or

scaffold is valuable but cannot be scored as an observed capability.

The integration also changed five live conclusions.

### 2.4 The dense ViT-B runtime blocker is retired

The retained official checkpoint loads strictly into 86.8M parameters. Finite CPU forwards pass at

The full P4 response surface is incomplete and resumable. The proof-level P4 artifact is still the

### 2.6 Studio conservatism was removed from the active entrypoints

The old implementation plan, README, cold-start file, scaling guide, Apple Silicon guide, and several

Wave E0 now binds F23, F29, and F39 to one immutable event, branch, lifecycle, arm, and control

## 3. Research thesis: the substrate is a controlled process, not a checkpoint

A useful owned substrate is not merely a smaller imitation of a frozen teacher. It is a persistent
process whose boundaries and update rules can be measured. Its scientific identity is the tuple:

```text
substrate = (
  state topology,
  event and referent identity,
  observation clocks,
  transition and prediction rules,
  memory lifecycle,
  plasticity policy,
  action interface,
  resource policy,
  verification contract
)
```

This definition changes the research objective from parameter count to useful controlled state.
The system should earn every new state variable by surviving a deletion, shuffle, restart, shell,
or matched-resource control. The strongest design can therefore be small, recurrent, factorized,
object-centered, event-driven, or externally memory-augmented.

The research record supports this direction:

- V-JEPA 2 and V-JEPA 2.1 demonstrate predictive latent video representations, but the official
  releases are best used here as frozen controls and dense feature instruments
  ([official repository](https://github.com/facebookresearch/vjepa2),
  [V-JEPA 2](https://arxiv.org/abs/2506.09985),
  [V-JEPA 2.1](https://arxiv.org/abs/2603.14482)).
- Perception Encoder reports that useful spatial and dense information can be stronger in
  intermediate layers than at the final output. This argues for layer and topology probes instead
  of treating one terminal embedding as the representation
  ([paper](https://arxiv.org/abs/2504.13181)).
- Compact object-centered latent world models can be more compute-efficient than pixel-generative
  alternatives, but object representations can drift during interaction and destabilize control.
  Object identity, intervention consistency, and latent drift must therefore be measured together
  ([compact manipulation model](https://arxiv.org/abs/2503.06170),
  [control failure analysis](https://arxiv.org/abs/2511.06136)).
- Experience replay can preserve adaptation in continual learning, but later evidence also warns
  that abrupt task boundaries may exaggerate plasticity loss. MOP must test gradual and abrupt
  worlds, replay and no-replay, and freshly initialized controls
  ([replay study](https://arxiv.org/abs/2503.20018),
  [gradual-change study](https://arxiv.org/abs/2602.09234)).
- Audio-visual systems benefit from concurrent temporal and spatial alignment. MOP should not flatten
  modalities into one pooled vector or assume exact synchrony
  ([ICLR 2025 paper](https://openreview.net/forum?id=1SYUKPeM12)).
- Event-based sensing shows why asynchronous change streams are a distinct computational interface,
  not just lower-frame-rate video. The local first rung is an event simulator with explicit sensor
  clocks and ambiguity, not a hardware purchase
  ([2026 review](https://arxiv.org/abs/2606.01280)).
- Functional monitoring is most useful when monitoring, evaluation, control, and adaptation are
  separated and tested at computational, algorithmic, and ecological levels
  ([framework](https://arxiv.org/abs/2605.23981)).

## 5. Perception through the machine

### 5.1 Vision

Vision should be represented as a controlled stream of observations, not a bag of clip embeddings.
The minimum useful visual record contains source bytes, transform identity, camera clock, frame
interval, crop/view, referent, event, occlusion state, uncertainty, and dense token geometry.

The active visual program has four arms:

1. frozen inherited dense features as measurement instruments;
2. exact-architecture random controls to test learned-code value;
3. handcrafted or low-capacity controls to expose trivial cues;
4. owned compact representations trained only after the input and control battery is citable.

Each arm should be tested on the same source events with off-ceiling tasks, wrong-time and wrong-
event controls, appearance-only controls, layer probes, dense versus pooled representations, and
held-out referents. Larger inherited variants have no active role unless the smallest instrument
fails a named representational requirement.

### 5.2 Native audio

Audio is the largest local gap because the current project does not yet possess a citable native
waveform-to-event path. A correct audio plane needs original waveform bytes, sample rate, channel
layout, clock origin, drift estimate, segment boundaries, source/event identity, preprocessing hash,
and rights card.

The first useful audio experiments are small:

- same-event versus wrong-event alignment;
- correct-time versus shifted-time alignment;
- visible-source versus off-screen-source localization;
- onset/offset boundary prediction;
- polyphonic mixture and source-count controls;
- audio-only, vision-only, early-fusion, late-fusion, and compact bottleneck arms;
- deliberate contradiction, missing-modality, and clock-drift trials.

The objective is not a large multimodal language model. It is a citable event-synchronized sensor
interface whose complementary information survives unimodal and shuffled controls.

### 5.3 Telemetry and internal sensing

Host telemetry, memory pressure, swap, thermal state, power source, task progress, uncertainty, and
error signals form a local internal-sensing interface. They are useful only if they predict or
change controlled behavior. A report that merely restates a logged value is not a self-monitoring
result. The test is whether calibrated telemetry forecasts failure, selects an intervention, avoids
measured work, and survives injection and lesion controls.

## 6. Event, object, and causal state

The project currently has several identity dialects. The next universal primitive should be a typed
event graph with immutable references for world, episode, event, entity, state, observation,
intervention branch, action, consequence, and memory revision.

The event model must represent:

- birth and first observation;
- persistence through transformation and occlusion;
- split, merge, composition, and separation;
- disappearance, termination, and reappearance;
- uncertain identity and explicit abstention;
- asynchronous sensor intervals and clock uncertainty;
- counterfactual branches from the same pre-action state;
- links between event state and memory revision.

This event layer is more important than adding another encoder. It lets vision, audio, action,
memory, prediction, and social reference describe the same occurrence without bespoke joins.

The smallest cross-family implementation is Wave E0. It uses three sentinels:

- F23 persistent referent identity;
- F29 controllability boundary;
- F39 memory availability forecast.

All three must share the same event bytes, branch identities, lifecycle state, arm/control schema,
and independently recomputed metrics. The output is mechanics-only even if its numbers are
favorable. If any sentinel needs experiment-specific identity or storage glue, the abstraction is
rejected or narrowed before the remaining expansion bank is scaffolded.

That test now passes at mechanics scope. The three sentinels share three units, nine controls, and
one mutation-tested verifier in `proof/EXPANSION_WAVE0.json`. Natural event identity, scientific
effects, and transfer remain open.

## 7. Prediction and counterfactual world models

A useful world model must predict consequences under intervention, not merely reconstruct likely
pixels. The local program should compare:

- reactive policy;
- model-free recurrent policy;
- compact latent transition model;
- object-centered transition model;
- oracle-state model;
- action-blind model;
- action-shuffled model;
- equal-depth unrolled control;
- exact replay and counterfactual branch verifier.

The core endpoints are held-out transition error, calibration, horizon degradation, intervention
ranking, planning benefit over reactive controls, exploitation failure, and cost per correct
decision. Generated environments are scientifically appropriate here because they provide exact
hidden state and counterfactual branches. Natural video later tests transfer; it cannot supply exact
counterfactual truth by itself.

That mechanics surface is now implemented in `proof/P7_ACTION_WORLD_MODEL_PREFLIGHT.json`. Three
independent seed/layout worlds execute all eight arms over exact same-parent four-action branches,
disjoint train/intervention/planning episodes, one-step and multi-horizon prediction, calibration,
true-dynamics planning, and six fail-closed replay mutations. Five neural arms match 1,360 trainable
parameters, 6,144 predictor calls, 2,048 decoder calls, and 7,667,712 counted linear MACs per unit.
The full receipt ran on one CPU thread in 7.1 seconds at about 300 MB peak RSS with no inherited
encoder, weights, download, or accelerator.

The result is intentionally negative at capability scope. The object-centered arm predicts position
better than the compact arm, but neither learned planner beats the reactive policy in any unit. The
fixture null is supported and scientific promotion is forbidden. What changed is the blocker:
rendering, same-state interventions, matched-depth controls, cost ledgers, and horizon/calibration
software are complete locally. The next valid P7 stage requires independently sourced rendered or
natural action trajectories, an exact-referent action control, and predeclared replication. It is a
data and external-validity gate, not a Studio gate.

## 8. Memory as a lifecycle

Memory should be an event-sourced governed ecology rather than one undifferentiated vector. The
minimum lifecycle contains encoding, indexing, availability, consolidation, replay, revision,
reconsolidation, deletion, provenance, conflict, poisoning, recovery, and prospective use.

The local comparison must match active bytes and compute across:

- exact global context;
- local window context;
- recurrence;
- hierarchical pooled memory;
- episodic retrieval;
- semantic summaries;
- replay and no-replay;
- restart and fresh-initialization controls.

P5 tests the first architectural boundary. The continual-stream scaffold now records retention,
acquisition, future learnability, stale-memory harm, deletion completeness, and exact resource use
under abrupt and gradual schedules. Its progressive 10,000, 100,000, and 1,000,000 event campaign
must establish experimental effects and independent-unit variance. More retained items are not
automatically better memory.

## 9. Plasticity and moldability

MOP needs to distinguish at least five change processes:

1. fast activation and working state;
2. episodic and external memory writes;
3. parameter updates;
4. structural growth, pruning, or routing changes;
5. governed self-rewrite of code or configuration.

Each process needs its own authority, time scale, rollback contract, and failure model. Plasticity
experiments must include future-learning tests, fresh-initialization controls, matched effective
steps, data-order controls, gradual and abrupt transitions, replay/no-replay, capacity-matched fixed
topology, and explicit compute/state budgets.

The CM7 null makes this more important. Objective labels alone did not produce a superior owned
substrate. The next response surface should vary one structural premise at a time, such as event
state, recurrence, factorized memory, local eligibility, growth/pruning, or routing. Every cell keeps
the strongest frozen, random, restart, and stronger-shell control. Futility rules prevent a five-
hour leg from becoming a ritual.

## 10. Workspace, monitoring, and resource allocation

A workspace is useful only if limited broadcast causes measurable cross-task benefit at controlled
cost. A monitoring layer is useful only if it predicts errors or resource needs and changes the
system accordingly. The experiment therefore needs:

- limited versus global versus no broadcast;
- matched communication bandwidth;
- lesion, injection, restoration, and stale-message controls;
- telemetry-grounded error and resource forecasts;
- calibrated uncertainty and abstention;
- measured avoided compute rather than hypothetical savings;
- construct dissociations so reporting, routing, memory, and prediction cannot collapse into one
  score.

The new local resource governor is also a practical version of this principle. It observes the host,
admits only declared tasks, preserves one exclusive heavy lane, allows safe light work, and pauses
only its own process group when user work, memory, swap, thermal, power, MPS, or disk gates require
it. Operational legs may run for up to 300 minutes. Existing scientific shards retain their frozen
configuration identity unless amended before new evidence is observed.

P9 now implements the monitoring half of this principle at structural-fixture scope. Five
independent workload families supply 260 disjoint train, calibration, and held-out lineages with
1,300 same-parent observational, pressure, and relief branches. Seven equal-capacity monitor arms
face fixed-threshold and oracle controls, including a correlational proxy that reverses at held-out
time. Exact resume, replay, calibration, intervention response, relief utility, end-to-end resource
accounting, and eight mutations all pass in `proof/P9_CAUSAL_MONITORING_PREFLIGHT.json`.

The causal abstraction beats the shifted correlational proxy on Brier score, ROC AUC, intervention
sign agreement, and controller utility in all five fixture units. That result is not promoted: the
equations construct the causal advantage, fixed-threshold controller comparisons are mixed, and no
natural failures or physical energy measurements exist. The next P9 rung is independent natural
workload and failure episodes, prospectively registered telemetry, real bounded interventions, and
replicated calibration. A meter with a named system boundary is separately required for energy.
Neither next step is a Studio compute boundary.

## 11. Development, embodiment, and ecology

Developmental evidence requires an ordered history whose order matters. A curriculum file by itself
is not development. The local first rung should use held-out generated worlds with progressive
sensorimotor competencies, play, tool acquisition, damage, repair, and transfer. It must compare
fixed versus adaptive curricula, shuffled stages, equal-data controls, restart controls, and
capacity-matched static models.

Embodiment begins with controllability: which observed changes are caused by the system's actions,
which are exogenous, and which belong to tools or other actors. The local action environment already
proves deterministic branch mechanics. The next rung adds rendered observations, compact world
models, active sensing costs, body/tool boundary changes, delayed effects, and held-out worlds.

Open-endedness is not an infinite run. It is measured expansion under fixed budgets. The bounded
local ecology should track novelty, diversity, competence, transfer, archive turnover, environment
complexity, failure recovery, and resource cost. Population search is a throughput multiplier, so it
must first run serially and prove that diversity changes the decision.

## 12. Social and cultural computation

The local first rung uses simulated partner populations to test joint reference, communicative
repair, teaching at equal information, partner transfer, and accumulation across generations.
Required controls include self-play versus held-out partners, no-message, shuffled-message,
equal-bandwidth nonsemantic signals, demonstration-only, and reset-each-generation conditions.

Success is not fluent output. It is improved coordination or transfer caused by a shared reference
protocol, surviving new partners and generations at matched information and compute.

## 13. Material and morphogenic bridge

The project can exhaust most material hypotheses locally before touching a specimen. A digital twin
should compare three material priors with conventional digital reservoirs under matched observable
state and readout:

- distributed recurrent and fading-memory dynamics;
- ionic or history-dependent state with drift;
- local morphogenic growth and repair.

The simulation battery should include damage, reconnection, calibration drift, noise, aging,
temperature-like nuisance, state observability, task transfer, digital-controller overhead, energy
proxy, and repeated virtual specimens. A material survivor must beat a tuned digital control on a
named Pareto axis and produce a bench-ready protocol. Only the physical stage is irreducible, because
real drift, fabrication variance, readout, and energy cannot be verified by more simulation.

## 14. Safety and governed rewrite

Any rewrite-capable path must be transactional. The minimum drill contains proposal, authority,
shadow execution, canary, conflict detection, interrupt, rollback, provenance, resource ceiling,
and forged-authority controls. Memory poisoning, evaluator tampering, stale checkpoints, source
drift, and partial writes are first-class adversaries.

The project should never reward a system for bypassing the evidence process. A rewrite is successful
only if it improves a preregistered endpoint, retains previous safety properties, survives the
stronger shell, and can be reverted exactly.

## 16. What could eventually require a Studio

A Studio becomes an earned scientific boundary only if all of these are true:

1. a scientifically relevant effect survives the compact local controls;
2. the required independent units, context, state, or real-time deadline are named;
3. the complete local path is measured end to end at least three times;
4. streaming, caching, factorization, recurrence, sequential seeds, precision changes, and bounded
   approximations have been attempted;
5. at least one reduction changes the estimand or reverses the decision;
6. the smallest enabling memory, bandwidth, or latency rung is calculated;
7. a parity-preserving next-rung pilot proves enablement, not convenience.

The only credible necessity classes are a non-factorizable resident state larger than the safe local
working set, a scientifically necessary real-time latency repeatedly missed, or synchronized
interaction that cannot be serialized or replayed without changing the estimand. More clips, more
seeds, more inherited parameters, or faster independent jobs are throughput benefits, not necessity.

The current evidence satisfies none of these gates. A purchase recommendation would therefore be
premature.

## 18. Bottom line

The project has moved from an encoder-centered collection of experiments to an owned, event-centered,
receipt-centered substrate program. The most important new work is not a larger model. It is the
shared event and lifecycle plane, native synchronized sensing, controlled compact world models,
governed memory and plasticity, and the experiment system that can tell when those ideas fail.

P4 and P5 remain the immediate heavy lane. Wave E0, the P6 stream plane, and P7's action/world-model
surface are implemented at mechanics scope. P7's fixture null removes any rationale for scaling that
exact regime, while P6's 10,000-event calibration remains the next admitted CPU rung after the heavy
lane clears. The 300-minute adaptive governor turns spare local time into evidence while protecting
foreground work. There is currently no earned Studio boundary.
