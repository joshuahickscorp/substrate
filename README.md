# Substrate v4

Substrate v4 is an evidence-bound developmental cognition runtime for executable structural models,
causal intervention, counterfactual reasoning, cross-representation alignment, structural inquiry, and
history-shaped specialization. It extends the existing runtime and preserves all v1, v2, and v3 evidence.
External activation is `false`.

The terminal v4 classification is:

```text
functional_proto_nous_candidate
```

This is a functional engineering and scientific classification. It is not an unqualified Nous claim and
does not imply consciousness, phenomenal experience, sentience, feeling, suffering, desire, personhood,
life, or moral status.

The principal campaign completed 2,136 independently checked work units and 181,560 episodes across 48
principal histories, 12 replication histories, and 12 generator-held-out open-world histories. All ten
principal hypotheses were positive, all 18 declared mutations were detected, and clean clone,
installation, tests, lint, checkpoint reproduction, body continuity, and activation checks passed.

Independent replication produced a real but sub-threshold effect:

```text
effect: 0.0310
95% bootstrap CI: [0.0231, 0.0398]
SESOI: 0.05
classification: mechanism_null
```

That null is the strongest missing condition for `nous_ready_for_review`; no review-candidate tag is
licensed.
