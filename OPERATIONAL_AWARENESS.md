# Operational Awareness

Protect live scientific work before optimizing developer throughput.

- Treat active run source, manifests, state, receipts, controls, seeds, thresholds, and worker policy as
  immutable.
- Use isolated worktrees, copied fixtures, separate output roots, bounded tests, and low-priority compute.
- Never interpret detached execution as permission to modify a supplying checkout.
- Prefer machine-readable state over process-name or narrative inference.
- Record exact commits, seals, commands, timings, and rollback tags at green checkpoints.
- Refuse promotion when evidence, identity, budget, or independent verification is incomplete.

Operational policy may change execution timing, never frozen scientific identity.
