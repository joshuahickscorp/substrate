# GENERATIONS: the one-page ladder

The whole project on one page. If you read nothing else, read this. It replaces the need to wade
through five eras of documents to understand where the work stands and why.

House style: no em or en dashes. A tie is a null. No positive enters a doc without an independent

## The substrate ladder (Stage 0 to 5)

The deep progression the whole program climbs. It is not about features; it is about what has been
scientifically EARNED, per matched unit of computation, under controls.

| Stage | Meaning | Status |
|---|---|---|
| 0 | Governance, measurement, falsification, recovery | complete |
| 1 | Programmable heterogeneous mechanics | complete |
| 2 | Counterfactual ecology and formation machinery | complete |
| 3 | Empirically useful active mechanisms | NOT achieved; first mechanisms failed or are blocked |
| 4 | Integrated architecture advantage | not entered |
| 5 | Natural, session-disjoint general validity | not entered |

**We are at Stage 2 of 5.** The system is mechanically formed and scientifically unformed. The
substrate preflight is honest about this: `scaffold_ready: true`, activation not ready, topology
mutation disabled. Everything below is the disciplined climb from Stage 2 toward Stage 3.

## Generation 0 (complete): three verified nulls that constrain everything after

Generation 0 built the constitution and ran the first mechanisms. All three headline results are
scientific NULLS, each independently re-executed from raw receipts (not just hash-checked; see
docs/INDEPENDENT_REVERIFICATION_2026_07_10.md, where all eight receipt chains reproduced). Nulls are
completions, not failures: they close branches and shape the next generation.

1. **X0 event formation: strong null (`strong_null_not_rejected`).** A stateless, delayed-scalar
   learned trigger saved about 38% of lifecycle work but destroyed about 97% of the required utility;
   both untrained controls beat it. The semantic oracle preserved utility while saving ~73% of work,
   so the headroom is real. The missing capability is relational and temporal event interpretation,
   not mere sparsity.
2. **P6 continual learning: verified null.** Replay improved retention in some comparisons but gave
   no future-learning benefit over no-replay, and lost to fresh initialization on abrupt change. This
   is the stability-plasticity split: fresh actors adapt but forget, replay actors retain but fail to
   adapt. Replay alone is not a theory of plasticity.
3. **EDCM complementarity: invalid bed, not a routing null.** Perspectives had uneven niches (one was
   harmful, none had unique positive niches), so forced universal complementarity was the wrong
   assumption. A dispatcher must not be trained against this bed.
4. **CM7 custom substrate: five-seed familywise-corrected null.** The 1.646M owned model's best
   learned objective lost to both the random-target and frozen-init controls. The exact regime is
   retired; the platform contracts, controls, and failure evidence carry forward. The verdict is
   airtight (tests/unit/test_cm7_independent_recompute.py re-derives it from the raw receipt).

The three negative constraints Generation 0 hands forward:

- sparse activation without event understanding is insufficient;
- heterogeneity must be competence-conditioned, not egalitarian;
- replay is not a complete theory of plasticity.

## Generation 1 (running): turn the inventory into a competence atlas

Generation 1 does not assume any organization wins. It builds the evidence that decides which, if
any, mechanism should ever be activated. Two strands:

- **The cognitive census** (`generation1-empirical-cognitive-corpus-v2`): 24 outer seeds by 128
  experiment classes across 15 capability packs, plus the mechanism scaffolds run fresh and
  independently re-executed (sensing, ecology, integrity, material-twin, broadcast, G0 formation, all
  R1 mechanics, `scientific_capability_claim: false`). Its job is a competence, null-result,
  seed-sensitivity, complementarity, and instrumentation atlas. Status at last read: 32 of 45 capsules
  complete, healthy, parked in `resource_wait` behind an external quantize process holding the heavy
  lane. It self-completes when that lane frees.
- **The scaffold consolidation**: every potential-atlas facet that was below scaffolding score 7 now
  has a fail-closed contract, deterministic fixtures, declared controls, and tests
  (docs/SCAFFOLD_CONSOLIDATION_2026_07_10.md). Readiness rose; confirmation still has to be earned.

### The Generation 1 mechanism epochs (what people have been calling "Generation 2")

These are the licensed hypotheses that the census feeds. They are documented in full in
`docs/mixture_of_perspectives/20_generation1_empirical_campaign.md` section 4 (the mechanism matrix)
and section 5 (the dependency graph). Each carries a positive route and a null-safe route; NONE may
start until the census corpus licenses it. Terminology note: the project folds these into Generation
1 as "mechanism epochs" rather than a separately named Generation 2; the content is identical.

| Epoch | Question | Forced by |
|---|---|---|
| G1-C0 | which existing cognitive traces are stable | prior few-seed studies |
| G1-C1 / C2 / D1 | reproducible disjoint niches, real complementarity, value-of-compute dispatch | EDCM invalid bed |
| G1-E1 | can relational and temporal state form useful events | X0 null with large oracle headroom |
| G1-M1 / V1 / K1 | bounded causal messaging, value-of-verification, contradiction repair | limited-broadcast and disagreement-only findings |
| G1-A1 / S1 / U1 / N1 | causal intervention, simulation-for-action, calibrated uncertainty, reducible-novelty curiosity | P7 planning null, uncertainty and curiosity nulls |
| G1-R1 | which memory organization improves future decisions | episodic-harm and replay findings |
| G1-P1 | can a stable core coexist with rapid adaptation | P6 stability-plasticity split |
| G1-G1 | can finite construction search form better shadow coalitions | G0 mechanics without efficacy |
| G1-I1 | does integrated ESCS beat simpler organizations | no current integrated advantage |

The three admission gates that keep this honest:

- **Gate R (registry): low.** A perspective enters if it is bounded, typed, reversible, measurable,
  and safe. It need not be globally useful.
- **Gate A (activation): selective.** A perspective activates only where competence, uncertainty,
  novelty, or conflict evidence warrants the compute.
- **Gate P (promotion): strict.** An architecture-level claim needs fresh independent verification,
  matched controls, and real cost measurement.

## What "formed substrate" will require (the Stage 3+ bar)

The substrate is scientifically formed only when all of these hold, each independently confirmed:
one learned event mechanism preserves useful events while cutting charged compute; two heterogeneous
perspectives show reproducible context-disjoint competence; dispatch beats matched sparse and fixed
controls; verification adds value selectively; retention and future learning improve jointly; memory
supports revision, provenance, deletion, and action, not only prediction; formation improves a sealed
multi-task objective after charging search cost; integrated ESCS improves the quality-versus-compute
Pareto frontier against strong matched baselines; the result survives fresh sessions, seeds, task
families, lesions, and independent reconstruction; and real resource measurements support the
efficiency claim.

Until then the honest description is: we built the operating system and safeguards for a
reorganizable intelligence, and the first campaign identified naive organizations that fail. The next
task is discovering mechanisms that actually earn selective activation, cooperation, memory,
plasticity, and structural change under matched cost.
