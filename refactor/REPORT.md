# Substrate: one Odyssey toward semi-conscious general intelligence

18 September 2026 · Implementation drop, research pass and source-only refactor review

## Target and scope

The explicit target is **semi-conscious general intelligence**, pursued by one continuing Odyssey. The source does not substitute a memory agent, a proto-agent label or six-world success for that target. The program's internal chapters organize distinct instruments and evidence obligations; they are not separate Odysseys.

Functional integration, breadth of competence and phenomenal interpretation remain separate questions. This release implements mechanisms and evidence contracts; it does not claim subjective experience, AGI, successful training or a completed main run.

## Implemented and connected

**Recurrent workspace and perspectives.** Typed, scoped representations carry subject, viewpoint, epistemic stance, source and parent links. Capacity-limited selection broadcasts to routing/retrieval consumers and the actual LLM request path. An input-guard critique can revise the next route. Developmental self forecasts are made before feedback and updated only after independently admitted outcomes. The same admitted experience cannot credit the cycle twice.

The no-workspace condition removes selection; no-broadcast retains private selection but denies consumer access; no-recurrence prevents later rounds; no-self removes the explicit self representation; no-perspective removes viewpoint/stance labels from organ context. They are mechanism interventions, not automatic consciousness tests. Native guards remain active in all conditions.

**Acquired structural reuse.** Distinct currently qualified numeric programs can yield role-normalized parameter/variable templates. Native learning searches those acquired templates before the primitive grammar under an accounted candidate/time allocation. The resulting program still needs verified witnesses and separate qualification. Search provenance records which acquired template, if any, contributed. This is bounded structural abstraction, not a general concept learner or learned neural search policy.

**One-program research ledger.** The charter fixes the requested target and internal chapter obligations. The ledger accepts complete, independently reviewed chapter records tied to design/source/artifact/history/domain/outcome identities. It reports support, counterevidence, inconclusive findings, missing axes and chapter readiness separately. Expired/revoked authority cannot satisfy current dependencies. Neither completed jobs nor positive mechanism findings award a consciousness verdict.

**Prospective apprenticeship contracts.** A weakness-driven inquiry proposal records approved sources and action/time budgets. Independent instrument admission binds source/license, oracle, adapter and allowed actions. A step commits observation and prediction before returning an action envelope. The envelope does not authorize itself. Real external dispatchers are not implemented by these contracts.

**Growth and physical manifestation.** `phenotype` measures current/historical reachable object payload, stable deduplication categories and native instruction counts. `growth` compares checkpoints without inferring intelligence from size. External neural bytes and actual process/device residency remain unknown without appropriate instruments.

**Whole-entity portable representation.** Export creates an NR-like manifest, complete frozen entity bundle, runtime binding, optional Safetensors statistics and explicitly supplied hashed assets. Restore verifies pins, payloads, state index and optional tensors, leaving the entity frozen without inherited host authority. The runtime and missing transitive organ dependencies are explicit. Safetensors inventory uses bounded headers and streaming hashes; unsupported dtypes are refused rather than guessed.

**Native image path.** Lowering binds the actual portable NR document, its pin, entity head, runtime and host—not an arbitrary unverified NR label. Qualified closed programs become serialized DAG regions. `NativeImage` checks source/plan consistency and independently signed fidelity/host qualification before use. It is an interpreter image, not generated CPU machine code, a neural model compiler or an executed FPGA bitstream.

## Physical and intellectual interpretation

A developing Substrate need not grow monotonically in every dimension. Runtime source can stay stable; evidence may accumulate; reusable organization may consolidate; neural parameter values may change without an increased parameter count; working memory depends on task and machine. None of those facts makes checkpoint size an intelligence scale.

The whole entity is a hybrid: organization, state, learned procedures, provenance, projects and attached neural artifacts. Hawking may eventually inherit or realize all relevant parts; this implementation does not impose a permanent partial-port restriction. Actual Hawking ABI mapping, full state-transition fidelity, neural fitting and accelerator lowering are still independent integration work. Renaming a JSON package NR/NX is not presented as that work having occurred.

The research pass draws on consciousness-indicator work including the 2025/2026 *Trends in Cognitive Sciences* paper, Block's access/phenomenal distinction, Seth's biological-naturalist challenge, an implemented embodied global-workspace study, Bengio's consciousness prior, DreamCoder, intelligence-measurement frameworks, responsible research and official Safetensors documentation. `docs/RESEARCH.md` supplies primary references and separates research implications from this implementation.

## Inspection, not execution

The source-only tool parsed/compiled 21 Python files without executing project code and inspected 1,713 statically resolvable calls for straightforward signature mismatches. Internal import/simple binding checks, JSON/TOML parsing, frontier-symbol checks and the full authored-line ceiling reported no errors in their limited scope. Original v2 test bodies were compared as AST data, not collected or run.

**No tests, test collection, Odyssey, project-module imports, model calls, services, containers, dependency installations or training jobs were executed.** Source-only inspection cannot establish behavioral correctness, sandbox safety, SQL behavior, host readiness, complete type correctness or a passing contract suite. No speedup, data-reduction ratio, inference latency or energy improvement was measured.

All 119 historical evidence payloads, totaling 139,163,029 uncompressed bytes, are retained byte-for-byte in the full archive and checked against the inherited path/SHA-256 inventory. The source-only archive omits those payloads. They remain evidence about their original artifacts, not qualification of this release.
