# Architecture

MOP converges on six maintained authorities:

1. mop.science: experiment records, execution, statistics, budgets, receipts, and artifact sealing.
2. mop.substrate: canonical event and evidence primitives.
3. Mechanism providers: unique state and scientific mathematics without local orchestration frameworks.
4. One campaign controller: scheduling, recovery, projections, and resource policy.
5. One typed registry/configuration tree: capability and frozen-identity authority.
6. One user interface: ordinary commands routed through a single CLI.

Experiments declare questions, nulls, sources, splits, independent units, treatments, controls, metrics,
SESOI, multiplicity, budgets, stop rules, claim ceilings, and an independent verifier. The engine owns
repeated lifecycle machinery. Independent verifiers do not import graded producer mathematics.

Historical schemas remain readable through explicit migration adapters; old active frameworks do not stay
maintained merely for file-path compatibility.
