# Local-first marketplace foundation

The first registry is local, explicit, and inspectable. It stores verified
capability-pack manifest references, never an implicitly trusted remote
marketplace catalog. An operator selects publisher keys, allowed pack names,
and capability ceilings locally.

A future marketplace may distribute signed packs, curricula, evaluation
suites, organ adapters, and entity templates, but it must preserve local trust,
license/SBOM review, artifact digest verification, revocation, and offline
inspection. It must not make a new pack executable simply because it appears
in a catalog.
