## 1. Why the next horizon is categorized

The first two successor horizons are intentionally organized around D1 and the complete mechanics
inventory. That is the right shape for proving fresh-seed robustness, but it is harder to read as
the mechanism program grows. This successor preserves the same fail-closed evidence boundaries
while grouping sibling work by scientific role.

The generic supervisor still runs one top-level category capsule at a time. Each category capsule
uses one dynamic process pool capped at eight workers and publishes eight deterministic,
time-balanced planning-shard descriptors. Those descriptors are not worker-pinned execution
partitions. The honest parallelism is therefore inside one category, followed by a serial
classify-and-seal barrier. No later wave can start from partial sibling receipts.
