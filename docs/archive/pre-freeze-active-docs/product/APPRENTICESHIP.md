# Autonomous apprenticeship

An apprenticeship is a bounded developmental program rather than an open-ended
agent loop. It specifies a specialty objective, approved packs and sources,
resource budget, wall-clock boundary, evaluator set, and evidence/assimilation
rules.

The current implementation plans worker allocation and source acquisition and
can record one source evidence item only through a typed, locally
cache-attested authority. It does not launch workers. The intended topology is
many disposable research or coding workers returning quarantined evidence to
one authoritative entity writer. Parallel work increases throughput on a
larger host; it does not create multiple entity timelines or broaden authority.

The first flagship evaluation remains a Go distributed-systems specialist:
baseline a frozen organ and controls, admit approved materials, execute hidden
repository tasks only through a future broker, and measure repairs,
concurrency diagnosis, continuation after interruption, and change adaptation.
No comparative capability result is claimed by this foundation.
