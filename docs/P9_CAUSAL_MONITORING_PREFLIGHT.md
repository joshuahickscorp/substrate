# P9 causal monitoring preflight

## Scope

This is the extended-compute P9 operational-self-model track. It is distinct from the registered
`p9_thought_without_language` philosophy experiment.

The pre-existing P9 implementation already accounts for wall time, CPU time, phase-boundary RSS,
process maximum RSS, accelerator allocation, storage change, retries, and idle time. It also blocks
energy claims until a wall-power meter defines a system boundary. That work measures cost. It did
not test whether internal telemetry carries prospective causal information about failure.

This preflight closes that mechanics gap only. It does not establish usefulness on a natural
workload, cognition, sentience, capability, physical failure behavior, or energy efficiency.

## Structural fixture

Five deterministic workload families each contain disjoint train, calibration, and held-out
lineages. Every lineage has one immutable parent state and five branches:

1. observational
2. queue pressure
3. memory pressure
4. retry pressure
5. resource relief

Failure is generated by one declared structural equation over post-intervention queue, memory,
retry debt, and a hidden shock. The monitor sees the first three variables but not the shock. The
same exogenous shock and base state are held fixed across all five branches, so intervention
comparisons do not silently change the parent episode.

A binary proxy is aligned with base risk in train and calibration lineages, then reversed in the
held-out lineages. It remains fixed across branches. This makes the distinction between a causal
signal and a correlational shortcut executable instead of rhetorical.

## Arms and matching

Seven monitor arms use the same eight-bin histogram capacity, the same fit rows, the same
calibration rows, and the same three smoothing candidates:

- causal abstraction
- correlational proxy
- lagged external error
- final-output token decoder
- random telemetry
- memory-lesioned telemetry
- deterministically shuffled causal telemetry

A fixed visible-risk threshold/PID-style controller and an oracle with the hidden shock are
structural controls. The oracle is a fixture-sensitivity check, not a candidate system.

All reported calibration values are exact rational quantities. Held-out metrics include Brier
score, expected calibration error, balanced accuracy, ROC AUC, prospective recall before external
error, same-parent intervention response, and utility after choosing the real paired relief branch.

## Replay, resume, and mutation contract

The dataset is built in 15 unit-by-split chunks. The preflight deliberately stops after chunk four,
resumes from an atomically written checkpoint, and requires an identical final dataset digest. Each
checkpoint record has a chunk digest and a rolling hash chain. A mutated checkpoint must be
rejected before construction resumes.

The exact dataset verifier rebuilds every row from the embedded config and rejects mutations to:

- future outcome
- intervention delta
- causal telemetry
- correlational proxy
- shuffle provenance
- lineage identity
- row digest
- dataset digest

The proof can also be rebuilt from the command line. Verification ignores measured timing and RSS,
then requires exact equality of the deterministic core:

```bash
.venv/bin/python scripts/p9_causal_monitoring_preflight.py
.venv/bin/python scripts/p9_causal_monitoring_preflight.py \
  --verify proof/P9_CAUSAL_MONITORING_PREFLIGHT.json
```

## Resource boundary

The preflight is one-thread CPU, has no model weights, performs no downloads, consumes no external
data, and must finish inside 10 wall seconds and 1 GiB process maximum RSS. Its own phases are
wrapped by the existing P9 workload accountant. Energy remains explicitly unmeasured.

## Evidence and remaining blocker

Evidence level is mechanics-only. A scientific promotion requires independent natural workload
and failure episodes, prospectively registered telemetry, real bounded interventions, replicated
held-out calibration, and an explicit metered boundary for any energy claim. Additional model size
or a Studio is not currently the blocker for this mechanics surface.
