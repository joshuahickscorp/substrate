# Event-Sourced Coalition Substrate

Status: research design, not an executed result
Scope: post-P5 architectural direction and post-EDCM-1 falsification program
Evidence date: 2026-07-11

## 1. Decision

The next architectural bet is not a larger inherited encoder, a smaller transformer, or a society of
pre-named visual, symbolic, planning, memory, and critique modules joined by a learned router. That would
leave the organization of intelligence unchanged: a bag of components, a shared vector convention, and a
coordinator trained from aggregate task loss.

The coherent alternative proposed here is an **Event-Sourced Coalition Substrate (ESCS)**:

> Intelligence is a persistent causal event graph updated by temporary, resource-priced coalitions of
> locally predictive actors. Actors communicate through event-grounded claims, receive counterfactual
> credit for marginal contribution, and are created, merged, repaired, or removed according to persistent
> predictive and decision value.

The event graph is the substrate. Coalitions, memory, communication, learning, arbitration, reflection,
and structural change are operations within one computational calculus. Modalities may retain different
payload forms, but event, referent, branch, consequence, provenance, cost, and credit semantics are shared.
Language is an optional adapter, not the internal currency.

This is a proposal to reorganize computation, not a claim that the organization is intelligent. It does not
receive "meaningful events" for free. Raw stream intake, change detection, identity tracking, factor
hypothesis formation, relevance estimation, indexing, dispatch, actor execution, credit, and archival
maintenance are all inside the measured system boundary. "Meaningful" is a retrospective causal evaluation,
not an oracle label available online.

The core claim is falsifiable: total lifecycle work, measured from raw observations through consequences and
retention, should scale primarily with useful event rate and active coalition size rather than raw sampling
rate, total actor count, total historical state, or a fixed token schedule. An oracle semantic header is a
nonpromotable upper bound. If a learned, fully charged event former cannot preserve decision quality while
retaining the full-system Pareto advantage, the event-driven efficiency premise is rejected.

### 2.3 What P5 and EDCM-1 can decide

P5 chooses a context-mechanism control for later work. If exact, windowed, recurrent, and hierarchical
context are tied within the registered SESOI, later experiments should use the cheapest noninferior arm.
If a directional pattern survives fresh training and independent verification, the winner and strongest
alternative should both remain controls. P5 does not, by itself, validate ESCS.

EDCM-1 is implemented and preregistered but intentionally unexecuted while P5 owns the heavy lane. It tests
hard event dispatch, four fixed heterogeneous specialists, typed messages, exact activation matching,
message interventions, and deterministic abstract work in generated partially observable worlds. Its
audit is `docs/audits/edcm1_event_triggered_coalition.md`.

EDCM-1 does not test event formation from raw sensing. It creates structured tick observations with stable
world and event identity, local geometry, relative goal, public feedback, and novelty channels; its sentinel
executes on every tick and a reactive proposer is always active. It can test selective expensive activation
and message mechanics after structured observations already exist. It cannot support claims about sparse raw
event formation, semantic-header cost, zero-work idle periods, learned referent discovery, decentralized
scaling, or actor ontogeny.

A favorable EDCM-1 result licenses a learned-dispatch experiment only. A complementarity-gate failure
means the bed cannot test routing and must not be used to claim a routing null. A strong null after a valid
gate kills the fixed sentinel on that task family, not the event-state premise.

## 3. Coherent computational organization

ESCS is not coherent merely because its components share a name. It has eight invariants that make every
component part of the same organization:

1. Raw adapters and the event former are components of the system, not free preprocessing.
2. External interaction follows four immutable event types: observation, hypothesis, commitment, and
   consequence. No event contains future information.
3. Every derived state version names the complete event-parent set that authorized it.
4. Online referents, factors, relevance, and reducibility are calibrated hypotheses, never evaluator truth.
5. Dispatch searches only a declared bounded candidate neighborhood and charges all control-plane work.
6. Endogenous reasoning may generate hypothesis events, but has finite depth, fanout, work, message, and
   wall-clock bounds.
7. Hot state and replayable payloads are bounded. Immutable commitments may survive payload compaction or
   erasure.
8. Every actor update, coalition decision, topology proposal, and archival operation is charged against
   causal value and measured resource cost.

Removing event identity would break state, messages, credit, replay, and verification together. That
shared dependency is deliberate. The proposal is one substrate with locally differentiated dynamics, not
independent modules that happen to exchange vectors.

The operational cycle is:

```text
raw packet, interrupt, clock, or control transition
-> charged adapter and candidate detection
-> append ObservationEvent, or abstain and charge the idle work
-> charged event former emits zero or more HypothesisEvents
-> retrieve and price a bounded local candidate set
-> explore or execute a temporary compatible coalition
-> exchange bounded typed claims
-> optionally emit bounded endogenous HypothesisEvents
-> append CommitmentEvent for action, abstention, memory write, deletion, or topology proposal
-> later append one or more ConsequenceEvents
-> assign local, interaction, decision, resilience, and resource credit
-> update actor state and, rarely, topology
-> compact, retain, archive, or erase payloads under the archival policy
```

When no ObservationEvent or endogenous HypothesisEvent is admitted, domain actors do not execute. Raw
adapters, candidate detectors, deadlines, and archive maintenance may still consume bounded idle work; that
measured work defines the system's idle floor. Quiescence occurs only when the event queue is empty, no
candidate coalition has positive expected value, and no expiry, deadline, or maintenance commitment is due.

## 4. Event semantics

### 4.1 Four-event lifecycle

Every event begins with one immutable envelope:

```text
event_envelope = {
  event_id,
  event_kind,
  causal_parent_ids,
  counterfactual_branch_id,
  clock_interval,
  clock_uncertainty,
  source_and_provenance,
  payload_digest,
  producer_state_version,
  measured_creation_cost,
  supersedes_event_ids
}
```

`causal_parent_ids` is plural because consequences, revisions, and composed claims may have more than one
cause. Revisions create new events that name what they supersede; no event is mutated in place.

An `ObservationEvent` records that a raw observation or control transition arrived. It does not contain an
action, a future consequence, canonical referent truth, or an evaluator label:

```text
ObservationEvent = event_envelope + {
  raw_packet_or_delta_refs,
  adapter_version,
  sensor_scope,
  transport_and_detection_cost
}
```

A `HypothesisEvent` records semantic adjudication, belief revision, contradiction, or endogenous simulation:

```text
HypothesisEvent = event_envelope + {
  origin: event_former | actor | verifier,
  epistemic_status: observed_candidate | inferred | simulated,
  referent_hypotheses,
  factor_change_distribution,
  decision_relevance_distribution,
  reducibility_distribution,
  supporting_event_ids,
  calibrated_confidence,
  abstention_reason,
  predicted_value_of_further_computation
}
```

Simulated hypotheses remain on explicit counterfactual branches and cannot silently become factual state.

A `CommitmentEvent` records a decision before the system acts or mutates state:

```text
CommitmentEvent = event_envelope + {
  coalition_id,
  commitment_kind: external_action | abstention | memory_write | deletion | topology_transaction,
  committed_payload,
  decision_distribution,
  deadline,
  predicted_utility_vector,
  predicted_full_cost
}
```

A `ConsequenceEvent` arrives later and binds an observed result to the prior commitment:

```text
ConsequenceEvent = event_envelope + {
  commitment_event_id,
  observed_outcome,
  realized_utility_vector,
  delayed_or_partial,
  observation_uncertainty,
  realized_full_cost
}
```

A commitment may receive zero, one, or several delayed consequence events. Earlier records are never filled
in retrospectively. Expiry, deadline, resource, provenance-correction, and deletion requests enter through
the same lifecycle as clock or control observations followed by hypotheses, commitments, and consequences.

"Meaningful event" is evaluation language. Online cognition sees observations and calibrated hypotheses;
causal value is determined later through consequences, interventions, and held-out use.

### 4.2 Fully charged event former

The event former is an explicit subsystem:

```text
event_former = {
  raw_stream_contracts,
  adapter_and_polling_state,
  candidate_detector,
  referent_hypothesis_tracker,
  factor_hypothesizer,
  relevance_and_reducibility_predictor,
  calibration_history,
  retained_state_bytes,
  predicted_operations,
  predicted_latency,
  lifecycle_status
}
```

It receives no hidden change point, niche, absolute identity, causal label, or evaluator factor. Hardware
interrupts, polling, packet coalescing, sensor transforms, re-identification, factor typing, header
serialization, discarded candidates, and idle checks are charged. Its outputs are distributions with
abstention, not canonical IDs. Ground-truth event, factor, and identity labels exist only in the evaluator.

An oracle event former is permitted only as a labeled nonpromotable ceiling. A header-only policy is a
mandatory control. If the header alone captures most decision value, event formation is functioning as a
cognitive actor and its complete training and deployment cost remains in the ESCS arm. False negatives,
detection delay, false event storms, idle work, calibration under unseen event types, and discarded-candidate
work are primary measurements.

Event-former training cost is amortized over a preregistered deployment horizon. The full accounting boundary
is:

```text
total_lifecycle_work =
    raw_transport_and_adapters
  + event_formation
  + indexing_and_graph_maintenance
  + dispatch_and_exploration
  + actor_execution
  + messages
  + counterfactual_credit
  + learning
  + archival_and_erasure
```

### 4.3 Event admission

An observation candidate may be admitted for one or more of the following, but these are predictions rather
than facts available for free:

- referent birth, split, merge, disappearance, reappearance, or uncertain re-identification;
- an action, delayed consequence, or externally visible state transition;
- a goal, deadline, memory-expiry, contradiction, safety, or resource-boundary transition;
- a calibrated prediction residual shown to be reducible by prior learning progress;
- an asynchronous sensor change that alters a decision-relevant factor;
- an explicit intervention, rollback, deletion, or provenance correction.

Raw novelty is never sufficient. A novelty channel may annotate an ObservationEvent, but it cannot authorize
a domain actor unless a separately calibrated and fully charged model predicts decision value or reducible
error. Fixed-rate sampling, raw-delta admission, novelty, uncertainty, and shuffled admission remain standing
controls. This rule directly inherits the noisy-TV failures.

## 5. State semantics

State has one organization with four bounded persistence levels:

1. A byte-bounded and time-bounded hot event journal containing replayable envelopes and payloads.
2. A versioned causal factor frontier derived from retained events.
3. Bounded local sufficient statistics owned by actors attached to graph scopes.
4. A cold archive containing immutable envelopes and content commitments, with payload retention governed
   separately.

The factor graph represents hypotheses rather than one committed world state. Competing identity,
relation, transition, or causal hypotheses may coexist with calibrated probabilities and explicit
abstention. Revisions create a new graph version and retain lineage to the evidence that changed it.

Graph payloads need not share one representation. A factor may contain a spatial relation, temporal
trajectory, probability distribution, motor affordance, compact symbol, program fragment, or scalar
constraint. Compatibility is established by event and factor scope, not embedding similarity.

Working state is the currently activated graph frontier. Episodic memory is the bounded hot journal plus
explicitly retained cold payloads. Semantic memory is a set of compressed, provenance-bearing factors whose
prospective value has survived a deletion or ablation control. These are persistence regimes within one
event system, not separately named memory modules.

Event envelopes and lineage commitments are immutable. Raw or derived payloads are not required to remain
forever. Replayable payloads may be encrypted or stored in independently erasable segments. Compaction
creates a versioned snapshot bound to prior segment roots; cold payloads may then be archived or erased under
a declared retention obligation. Retrieval, compaction, snapshot, cold-storage, and deletion work are all
charged.

A complete deletion removes the payload, retrieval keys, indices, caches, and derived factors that depend
exclusively on it; destroys any independently stored payload key or keyed-commitment secret; and appends a
deletion CommitmentEvent followed by a ConsequenceEvent. Only a non-content-bearing lineage marker may
remain. Exact replay is then marked unavailable beyond that deletion boundary.

Any scientific claim requiring deterministic regeneration must be verified before erasure or retain an
authorized replay snapshot. A result may not simultaneously claim deletion completeness and byte-exact
reconstruction from deleted payloads. Hot-journal bytes, cold bytes, retained byte-time, retrieval work,
compaction work, erasure completeness, and loss of replay authority are explicit endpoints.

## 6. Actor semantics

Experiments 0 through 2 use fixed actor implementations and may learn scope, calibration, state, and
communication. They do not test invention of new computational forms. "Emergent specialization" means a
reproducible causal role acquired from neutral initialization within a declared actor grammar, not a post-hoc
name applied to a preinstalled specialist.

Every actor implements the same contract:

```text
actor = {
  actor_id,
  subscribed_event_types,
  causal_factor_scope,
  local_state,
  prediction_or_action_distribution,
  calibration_history,
  predicted_operation_cost,
  predicted_message_cost,
  update_rule,
  grammar_genotype,
  lifecycle_status
}
```

Actors become heterogeneous through learned scope, state dynamics, timescale, and payload form. They are
not permanently declared to be visual, symbolic, causal, planner, verifier, or memory actors. Modality
adapters are sensors. An actor earns a functional description only when causal lesions and held-out
interventions show what information and decisions it contributes.

An actor has no right to inspect the private state or output of an inactive actor. Inactive actors receive
neither proposal calls nor learning updates. Their only permitted activity is a bounded header-level cost
and readiness estimate maintained from past activations.

The fixed actors in Experiments 1 and 2 may be mechanically different, as EDCM-1's proposers are, but such
difference is designed heterogeneity rather than emerged differentiation. Experiment 3 may make a stronger
claim only through the finite `G0` construction grammar in Section 10. If `G0` is not implemented, the
structural claim narrows to scope allocation, merge, pruning, and repair within fixed actor families.

## 7. Activation, arbitration, and halting

Before any actor executes, a dispatch mechanism reads only the HypothesisEvent header, bounded subscription
state, resource prices, and past calibration. It cannot inspect unexecuted proposals. Candidate retrieval is
capped at `K` actors, coalition size at `C`, beam width at `B`, local nomination depth at `H`, message edges at
`M`, and endogenous reasoning rounds at `R`. Exact global search is permitted only on small calibration units
as a nonpromotable regret oracle.

For actor `i`, the individual estimate remains:

```text
bid_i = E[decision-loss reduction_i | hypothesis header, history]
        - compute_price * predicted_operations_i
        - bandwidth_price * predicted_bytes_i
        - stale_state_risk_i
        - deadline_risk_i
```

Interaction-aware dispatch also estimates bounded coalition value `V(C | header, history)` for candidate
coalitions admitted by declared compatibility edges. The selector uses a capped beam or equivalent bounded
algorithm; it never scans arbitrary actor subsets while calling that cost free.

Three dispatch organizations remain experimental alternatives:

- **Bounded-central:** one scheduler processes the capped candidate set, with no full actor scan.
- **Sharded subscription:** an event reaches at most `S` factor-scope shards, each returns at most `b` bids,
  and a bounded merger selects among them.
- **Peer nomination:** subscription entry actors may nominate at most `d` compatible neighbors for at most
  `H` hops; no component enumerates the full population.

The selected actors form a temporary coalition and alone receive the authorized event payload. Cooperation
occurs when actor claims cover compatible factors needed by one decision. Competition occurs when claims
predict incompatible outcomes or actions. Arbitration minimizes registered decision loss plus full resource
cost under source reliability, expiry, provenance, and safety constraints. Confidence alone never wins.

ESCS makes no decentralization, ecosystem, society, or ant-colony claim unless a sharded or peer-nominated
arm contributes a new held-out Pareto point over bounded-central dispatch. If bounded-central wins, it remains
an admissible engineering design but must be described as centralized arbitration.

### 7.1 Endogenous reasoning events

EDCM-1 retains its preregistered one-verifier-round limit. ESCS more generally allows an actor or verifier to
emit an endogenous HypothesisEvent when its predicted marginal value of further computation is positive.
Such an event may re-enter bounded dispatch without a new external observation.

Every reasoning episode declares maximum chain depth, branch fanout, coalition activations, operations,
message bytes, wall-clock time, repeated-state cycle rule, and counterfactual retention. Simulated events stay
on explicit branches and cannot update the factual frontier until an external ConsequenceEvent supplies
evidence. Adaptive-depth reasoning must beat zero-round, one-round, exact-rate periodic, shuffled-round, and
equal-work recurrent or unrolled controls.

Computation halts when any of the following becomes true:

- the queue is empty and no remaining compatible coalition has positive expected value;
- calibrated decision risk falls below the registered threshold;
- the action deadline is reached;
- a resource or safety event raises the price above expected value;
- an endogenous chain repeats a registered state digest without new evidence;
- the registered reasoning, verification, branch, message, or work budget is exhausted.

At exhaustion the system acts or abstains. Further rounds are evidence-bearing only when they provide
independent causal value over their rate-matched and equal-work controls.

## 8. Message semantics

Messages share a header, not a latent code:

```text
message = {
  message_id,
  source_hypothesis_event_ids,
  referent_hypotheses,
  branch_id,
  factor_scope,
  claim_type,
  epistemic_status,
  hypothesis_or_action_distribution,
  supporting_event_ids,
  producer_actor_id,
  producer_state_version,
  calibrated_confidence,
  expiry,
  predicted_utility,
  producer_operations,
  encoded_bytes,
  payload_form
}
```

Payloads may be spatial graphs, trajectories, probability tables, motor programs, constraints, compact
symbols, or other registered forms. A receiver must validate event identity, hypothesized referent scope,
branch, epistemic status, source-state version, freshness, and schema before using the payload. Inferred or
simulated content cannot be represented as an observed fact merely by crossing a message boundary.

The system does not assume that useful private coordinates recur across seeds. Cross-seed and cross-actor
interoperability is tested through consequence-grounded message use, not raw latent alignment. Delayed,
wrong, shuffled, corrupted, absent, and restored messages remain standing controls.

Shared event and message schemas are a symbolic interlingua even though they are not natural language or a
universal latent vector. Schema-permutation, split, merge, unseen-factor, and no-oracle-adapter conditions are
therefore required before claiming representation-independent interoperability.

## 9. Learning and credit semantics

Every activated actor maintains a bounded eligibility trace. It receives three distinct signals:

1. Immediate local prediction residual on its declared factor scope.
2. Delayed decision credit from observed action consequences.
3. An explicit debit for executed operations, retained state, and message bytes.

Where the environment supports same-state forks, actor credit is a difference reward:

```text
D_i = utility(coalition)
      - utility(coalition without actor_i)
      - compute_price * actor_operations_i
      - bandwidth_price * actor_bytes_i
```

Exact counterfactual credit is used on a calibration subset. A learned critic may approximate it later,
but must remain calibrated against unseen exact forks. The dispatcher learns from realized `D_i`, not
self-reported confidence or aggregate end reward alone.

Individual leave-one-out credit cannot discover every interaction or distinguish uselessness from
substitutable redundancy. On a bounded calibration subset ESCS therefore also measures pairwise interaction:

```text
I_ij(C) = utility(C)
          - utility(C without actor_i)
          - utility(C without actor_j)
          + utility(C without both actor_i and actor_j)
```

Higher-order exact credit is an oracle diagnostic only unless a separately bounded approximation is
registered. All forks, critic training, interaction assays, and failed coalition trials count toward
lifecycle work and are amortized over a declared horizon.

### 9.1 Coalition discovery and exploration

An actor cannot earn calibration if it is never selected. A preregistered fraction of safe training or
calibration opportunities may therefore test under-sampled compatible coalitions. Exploration is driven by
coverage debt or calibrated uncertainty about reducible coalition value, never raw sensory novelty. Its
coalition size, trials, operations, messages, safety exposure, and wall time are capped.

No-exploration, random exploration at the same rate, individual-only credit, and oracle coalition search are
mandatory controls. Held-out deployment cannot query oracle forks. Dormant actors carry staleness estimates
and pay all replay or catch-up cost when reactivated. A useful pair that has no positive individual cold-start
signal, redundant substitutes, a regime-shift actor, and a long-dormant actor are standing discovery assays.

Local actor updates combine the factor prediction residual with eligibility-weighted difference credit.
No inactive actor is updated. A global outcome scalar may modulate eligible local updates, but it does not
specify the actor's representation or gradient.

Pruning may not use leave-one-out decision value alone. It must separate nonuseful computation from
substitutable redundancy and report resilience value under paired lesions. A redundant actor may be retained
only when its measured fault-tolerance contribution exceeds retained-state, update, and dispatch cost.

Memory writes use the same rule. Surprise alone does not authorize storage. An event payload is retained,
compressed, archived, or erased only when prospective-use estimates, provenance obligations, replay
authority, or revision/deletion semantics justify its state, retrieval, compaction, and deletion cost.

## 10. Structural plasticity semantics

Structural search is bounded by finite construction grammar `G0`:

```text
state primitives:
  bounded scalar or vector distributions
  bounded categorical tables
  bounded temporal deques
  bounded typed factor subgraphs
  bounded recurrent state

operator primitives:
  affine or nonlinear local update
  table lookup or update
  temporal accumulation
  graph-neighborhood aggregation
  constraint filtering or propagation
  bounded retrieval
  bounded rollout or search
  typed message transform and emit

composition bounds:
  maximum operator nodes and DAG depth
  maximum state bytes and operations per activation
  maximum message bytes and edges

allowed mutations:
  clone an actor
  split or merge factor scope
  add, remove, or replace one G0 operator
  adjust a bounded timescale or memory capacity
  add or remove one typed message edge
  merge causally redundant actors

forbidden:
  arbitrary generated code
  unbounded recursion
  undeclared operators
  silent schema creation
  mutation outside transactional governance
```

Every actor genotype, mutation, initialization seed, shadow-training exposure, failed candidate, and
evaluation cost is logged and charged. `G0` tests structural search over a finite computational language; it
cannot establish open-ended invention beyond that language. If `G0` is not implemented, Experiment 3 is
renamed scope allocation, merge, pruning, and repair within fixed actor families, and no new-perspective or
morphogenesis claim is admissible.

Topology change is rare, transactional, and reversible:

- Birth or split is proposed when a persistent reducible residual remains and a `G0` candidate adds
  complementary held-out decision value after all candidate-generation and shadow costs.
- Merge is proposed when actors are causally redundant under matched lesions.
- Pruning is proposed when long-run marginal value after full cost is nonpositive.
- Repair is proposed when a lesion selectively damages a previously verified function and a bounded
  intervention restores it without protected regressions.

Every proposal runs through shadow, canary, CommitmentEvent, ConsequenceEvent, rollback, and lineage checks.
Final-capacity-from-start, same-final-genotype-from-start, same-grammar random search, mutation-disabled,
fixed spare capacity, restart, and full retraining are mandatory controls. Growth is not evidence of
development, and recovery is not evidence of repair unless function returns on held-out inputs without
simply relearning from the original training stream. Functional emergence further requires neutral
initialization and recurrence after actor-ID, scope-label, and topology permutation.

## 11. Evaluation across the ten required axes

| Axis | ESCS assessment and required evidence |
| --- | --- |
| Biological plausibility | Sparse events, local state, eligibility traces, bounded memory, outcome modulation, and dynamic coalitions are biologically suggestive. A canonical event ledger, exact forks, and bounded-central dispatch are engineering mechanisms, not biological models. No neural, developmental, or biological-equivalence claim follows. Existing biological-schedule nulls remain binding. |
| Computational plausibility | The four-event lifecycle is finite, but plausibility requires explicit bounds on event formation, candidate retrieval, coalition beam width, endogenous chains, hot state, forks, and archive maintenance. Exact global search and evaluator semantic labels are oracle diagnostics only. |
| Engineering feasibility | Medium at isolated-mechanics scope and lower for an integrated system. Wave E0 supplies identity mechanics, EDCM supplies structured-observation dispatch and message accounting, P6 supplies persistent streams, P7 supplies exact branches, P9 supplies causal monitoring, and governed rewrite supplies transaction controls. Raw event formation, learned interaction credit, bounded distributed dispatch, archival erasure, and safe `G0` topology change remain hard additions. |
| Scaling behavior | With raw rate `r`, admitted hypothesis rate `e`, at most `K` candidates, coalition cap `C`, beam `B`, message cap `M`, and bounded hot state, the testable target is approximately `O(r * event_former_cost + e * (index_cost + bounded_dispatch(K,C,B) + active_actor_work + M) + archive_cost)`. It is not assumed independent of total actors or history until dormant-population, subscription-density, log-length, and event-storm slopes are measured. |
| Sample efficiency | Local reuse, provenance-bearing state, bounded exact branches, and actor-specific updates may reduce samples. ## 12. Experiment 0: Charged event formation and idle boundary

### Question

Can an event former operating on raw asynchronous streams preserve decision quality and reduce total
lifecycle work without semantic labels supplied by the evaluator?

### Arms

- learned fully charged event former;
- fixed raw-delta detector;
- raw periodic schedule;
- always-on tick processing;
- header-only policy;
- novelty detector;
- uncertainty detector;
- exact-rate shuffled candidate admission;
- oracle semantic event former as a nonpromotable upper bound.

Use raw generated sensor streams with long idle intervals, irrelevant high-rate changes, sparse
decision-relevant changes, delayed consequences, correlated event storms, uncertain identity, unseen event
types, and asynchronous clocks. Evaluator labels score detection but are never visible to cognition.

### Primary endpoints

- held-out utility versus total lifecycle work;
- event precision, recall, and delay using evaluator-only labels;
- idle adapter and event-former work;
- false activation under noisy TV;
- header-only action value and encoded bytes;
- queue stability and deadline misses under event storms;
- calibration and transfer across unseen event and clock families.

### Positive criterion

Across at least five paired seeds and a disjoint fresh verifier:

- utility is within 0.01 of always-on;
- total lifecycle work, including event formation, is at least 25 percent lower than always-on;
- Pareto contribution is positive over fixed-delta, periodic, shuffled, novelty, and uncertainty controls;
- no hidden semantic label or oracle mapping is available to the learned arm;
- irreducible noise produces no excess activation;
- predicted event value remains calibrated on unseen worlds and event families.

### Decisive null

Only the oracle event former works; useful event rate approaches raw update rate; false negatives or delay
erase utility; the header performs essentially all task cognition without a full-system Pareto gain; or event
formation, idle polling, indexing, and queue overhead erase the saving. Experiment 0 must pass before any
integrated ESCS event-driven efficiency claim. EDCM-1 and Experiment 1 may still support narrower dispatch
mechanics claims on structured observations.

## 13. Experiment 1: Counterfactual value-of-computation dispatch

### Question

Can dispatch be learned from an actor's causal marginal value rather than hard-coded thresholds,
confidence, uncertainty, or aggregate end reward?

### Entry gate

EDCM-1 must pass its independent complementarity gate. A gate failure means the environment cannot test
routing and blocks this experiment. If EDCM-1 clears complementarity but supports its strong null, this is
the one licensed premise change from fixed to learned dispatch. Experiment 0 is not required for this narrow
structured-observation mechanism study, but Experiment 1 cannot promote integrated event-driven efficiency
unless Experiment 0 also passes.

### Arms

- interaction-aware ESCS dispatcher trained from bounded exact same-state credit;
- bounded-central, sharded-subscription, and peer-nomination dispatch organizations;
- individual-only credit;
- no exploration and exact-rate random exploration;
- EDCM-1 hard sentinel;
- outcome-only bandit router;
- uncertainty gate;
- novelty gate;
- always-on coalition;
- exact-rate periodic schedule;
- exact-rate shuffled schedule;
- exact-total-rate homogeneous actors;
- tuned best single actor;
- equal-budget recurrent monolith;
- oracle dispatch as a nonpromotable upper bound.

Use the complementarity-calibrated EDCM worlds plus held-out world families. Retain noisy-TV, message
delay, corruption, lesion, restoration, verifier lesion, and exact-bandwidth controls. The dispatcher may
use bounded exact forks during training and calibration, but held-out deployment cannot query an oracle.
Add a useful actor pair with no positive individual cold-start signal, redundant substitutes, a regime-shift
actor, long-dormant reactivation, actor-population scaling, subscription-density scaling, and event storms.
Use a tune split to select one preregistered bounded dispatch organization; freeze it before held-out
comparison and correct any familywise selection claim.

### Primary endpoints

- held-out utility versus full-system work;
- Pareto and hypervolume contribution;
- regret to oracle dispatch;
- calibration of predicted individual, pairwise, and coalition value;
- discovery rate and work for complementary actor pairs;
- redundancy versus resilience credit;
- utility and dispatch work as dormant actor count and subscription density grow;
- queue stability, event-storm recovery, and deadline misses;
- exploration, exact-fork, critic-training, and stale-reactivation work;
- cross-world activation transfer;
- noisy-TV false activation;
- causal actor and message lesion effects;
- learning curve per exact counterfactual intervention consumed.

### Positive criterion

Across at least five paired seeds and a disjoint fresh verifier:

- utility is within 0.01 of always-on;
- full-system work is at least 25 percent lower than always-on;
- Pareto contribution is positive over the hard sentinel and every rate-matched control;
- predicted marginal value remains calibrated on unseen worlds;
- the registered complementary pair is discovered without oracle activation and beats random exploration;
- bounded dispatch retains its registered latency and work slope as dormant actors and event bursts grow;
- irreducible noise produces no excess activation;
- lesion of a high-credit actor or message selectively reduces the endpoint it claims to support.

### Decisive null

No held-out Pareto gain; equivalence to uncertainty, periodic dispatch, individual-only credit, or random
exploration; failure to discover jointly useful actors without oracle enumeration; material dependence on
total dormant actors or a global scan; dependence on oracle forks at test time; unstable event-storm queues;
failure under noisy TV; or absence of selective lesion effects. A valid EDCM-1 null followed by this null
retires adaptive coalition dispatch on this task family. If bounded-central wins, retain it as centralized
arbitration and reject decentralization or ecosystem language.

## 14. Experiment 2: Causal event graph versus vector/history state

### Question

Does event-sourced causal state improve prospective decisions or computational efficiency beyond
bookkeeping and provenance?

### Environment

Construct session-disjoint held-out worlds requiring:

- identity through occlusion, transformation, split, merge, and reappearance;
- asynchronous visual, audio-like, action, and telemetry clocks;
- delayed action consequences and same-parent counterfactual branches;
- contradictory, stale, poisoned, revised, and deleted memories;
- ambiguity requiring calibrated abstention;
- world-family transfer rather than map memorization;
- canonical, permuted, split, merged, and unseen factor schemas without oracle mappings;
- increasing hot-log length, cold segments, branch count, revision count, and deletion pressure.

Build this on the P6 lifecycle and P7 branch machinery rather than creating a parallel identity dialect.
P5 determines the context-mechanism control used in the comparison. Raw observations and the charged event
former are required for a capability or efficiency result. An oracle semantic header may be used only for a
separately labeled mechanics arm.

### Arms

- ESCS event and causal factor graph with typed messages, bounded hot journal, and erasable cold archive;
- ESCS with canonical versus changed schemas and no oracle adapter;
- unbounded replay log as a non-efficiency upper bound;
- P5's winning or cheapest noninferior context mechanism;
- exact global history;
- tuned recurrent or state-space state;
- episodic key-value memory;
- compressed raw history;
- action-blind, action-shuffled, and referent-shuffled controls;
- reactive lower bound;
- oracle-state nonpromotable upper bound.

Match trainable parameters, active operations, retained byte-time, update count, observation rights, and
action budget. The ESCS arm pays for raw adapters, event formation, indexing, dispatch, messages, provenance,
retrieval, compaction, snapshots, deletion, and lost replay authority.

### Primary endpoints

- held-out counterfactual action ranking and realized utility;
- identity and revision correctness;
- stale-memory harm and poisoning recovery;
- deletion completeness and absence of recoverable payload or dependent indices;
- compaction parity, cold-retrieval latency, and replay-authority status;
- work and retained-state slopes as irrelevant history, branches, and revisions grow;
- schema adaptation samples, work, and transfer without an oracle map;
- calibration and abstention;
- work, bytes, wall time, and peak state per correct decision;
- transfer across world and sensor-clock families.

### Positive criterion

The ESCS arm must either:

- improve held-out intervention-ranking accuracy by at least 0.05 with a positive paired confidence bound
  over every learned control at no greater full-system work and state; or
- match the best control inside its SESOI while reducing full-system work by at least 30 percent.

It must also pass every revision, poisoning, bounded-state, compaction, deletion, provenance, schema-transfer,
and abstention gate on all registered units.

### Decisive null

The graph improves identity bookkeeping but not prospective decisions; a compressed history, recurrent
state, or key-value memory matches its quality and cost; canonical-schema dependence blocks transfer; useful
work or retained state grows with irrelevant history at a rate matched controls avoid; or bounded compaction
and real deletion remove the claimed benefit. This result retains the event graph as proof infrastructure but
rejects it as a superior organization of intelligence.

## 15. Experiment 3: Structural coalition ontogeny and repair

### Question

Can actor birth, differentiation, merging, pruning, and repair improve adaptation and robustness beyond
fixed final capacity, tuned replay, and restart?

### Entry gate

At least one of counterfactual dispatch or event-state factorization must survive its strongest controls.
Otherwise an integrated structural system would hide which failed premise it was compensating for. `G0`,
its bounds, genotype receipts, mutation operators, and cost accounting must be frozen before execution. If
`G0` is absent, the registered question narrows to scope allocation, merge, pruning, and repair within fixed
actor families.

### Environment

Use long abrupt and gradual streams containing recurring niches, genuinely new regimes, selective actor
lesions, sensor failures, later return of old regimes, and untouched future-learning episodes. Every
structural proposal is evaluated on a disjoint shadow and canary lineage before commitment. Include neutral
initialization plus actor-ID, scope-label, and topology permutations.

### Arms

- ESCS `G0` birth, split, merge, repair, and prune under interaction-aware credit;
- fixed final capacity available from the first event;
- same final genotype available from the first event;
- same-grammar random search and mutation-disabled controls;
- fixed sparse MoE or kWTA;
- random growth and pruning;
- tuned replay plus EWC;
- fixed spare capacity;
- dense recurrent monolith;
- restart from the current stream position;
- full retraining as a non-efficiency upper bound.

Match final capacity, cumulative updates, observation exposure, replay bytes, candidate-generation exposure,
and full-system work where the scientific comparison requires it. Charge failed candidates, shadow learning,
canary evaluation, rollback, compaction, and retained genotypes. Report both matched-final-capacity and
matched-cumulative-resource planes.

### Primary endpoints

- retention and future learnability;
- adaptation speed to new regimes;
- interference with old regimes;
- selective lesion loss and recovery without original-stream retraining;
- old-function protection after repair;
- cumulative work, peak state, replay bytes, and topology churn;
- candidate trials, failed-candidate work, rollback, and genotype complexity;
- transfer of functional specialization across seeds, ID/scope/topology permutations, and held-out world
  families.

### Positive criterion

The ESCS arm needs a positive paired confidence bound over every fixed or random structural control on both
online-utility area and post-lesion recovery, while:

- cumulative work and peak state do not exceed the matched control;
- old-regime regression remains inside a preregistered SESOI;
- future learnability improves rather than merely shifting capacity to the newest regime;
- repair survives new inputs without replaying the original training stream;
- topology churn remains bounded;
- functional roles recur after neutral initialization and registered permutations;
- the same-final-genotype-from-start and same-grammar random controls do not match the frontier.

### Decisive null

Fixed final capacity, the same final genotype from the first event, same-grammar random search, tuned replay,
spare capacity, random growth, restart, or full retraining matches the frontier; candidate and shadow costs
erase the gain; or apparent roles disappear under neutral initialization or registered permutations. This
retires morphogenic topology as a useful mechanism and leaves the strongest surviving fixed or scope-adaptive
event-driven coalition form.

## 17. Explicit kill criteria

### 17.0 Kill event-driven efficiency if

- Experiment 0 depends on evaluator referents, factor labels, hidden change points, or an oracle semantic
  mapping;
- the charged event former cannot preserve utility, or useful event rate approaches raw update rate;
- false negatives, detection delay, idle polling, indexing, or header construction erase the Pareto gain;
- event storms make the admitted queue unstable or activation effectively dense;
- a header-only policy shows that uncounted event formation already performs the task.

This kill may leave ESCS as a structured-observation dispatch or proof architecture. It rejects the claim that
the integrated system sleeps cheaply until learned meaningful change.

### 17.1 Kill adaptive coalition dispatch if

- EDCM-1 passes complementarity but supports its strong null, and Experiment 1 also fails its Pareto or
  causal-lesion criterion;
- the learned dispatcher requires inactive outputs, hidden evaluator state, or oracle forks at deployment;
- uncertainty, novelty, periodic, shuffled, individual-only, or rate-matched random exploration matches it;
- useful complementary actors cannot be discovered without oracle coalition enumeration;
- bounded dispatch materially scales with dormant actor count, requires a global scan, or misses its queue
  and deadline bounds;
- exploration, exact-credit, critic, dispatch, indexing, and message overhead erase the claimed savings.

If bounded-central dispatch survives while sharded and peer-nominated dispatch do not, retain centralized
arbitration and kill decentralization, society, ecosystem, and ant-colony interpretations.

### 17.2 Kill the event graph as an intelligence organization if

- Experiment 2 improves provenance or replay integrity but not held-out decisions, planning, calibration,
  robustness, or cost;
- compressed raw history, a recurrent state, or key-value memory lies on the same or a better full-system
  Pareto frontier;
- event identity does not survive sensor-clock, branch, revision, poisoning, and deletion attacks;
- useful operation requires a universal latent alignment or canonical symbolic ontology that fails changed-
  schema, cross-seed, or cross-partner controls;
- useful work or retained state grows with irrelevant history at a rate matched controls avoid;
- bounded compaction or genuine payload deletion removes the claimed decision benefit, or deleted content
  remains recoverable through payloads, keys, indices, caches, or derived factors.

The event graph may remain as evidence infrastructure after this kill. It must not be described as a
capability mechanism.

### 17.3 Kill structural ontogeny if

- `G0` is absent while the result is described as actor birth, new computation, or morphogenesis;
- fixed final capacity, the same final genotype from the first event, same-grammar random search, tuned replay,
  spare capacity, random growth, restart, or full retraining matches adaptation and recovery at equal or lower
  cost;
- apparent growth benefit is explained by extra parameters, updates, data, replay, candidate trials, or
  shadow/canary work;
- repair is ordinary retraining on the original stream;
- topology churn, catastrophic interference, or rollback frequency exceeds its registered bound;
- functional roles do not transfer across seeds or held-out regimes, or disappear under neutral
  initialization, actor-ID, scope-label, or topology permutation.

### 17.4 Kill endogenous reasoning if

- adaptive HypothesisEvent chains tie zero-round, one-round, periodic, shuffled, or equal-work recurrent and
  unrolled controls;
- the apparent benefit is hidden compute inside one actor rather than event-authorized cooperation;
- simulated hypotheses contaminate factual state without an external consequence;
- repeated-state cycles, queue growth, branch growth, or budget overruns prevent quiescence.

This kill restores the one-round or cheapest noninferior context control for the tested task family. It does
not kill external event dispatch by itself.

### 17.5 Kill ESCS as the preferred integrated direction if

- charged event formation fails and the claimed advantage depends on structured oracle headers;
- both adaptive dispatch and event-state factorization meet their decisive nulls;
- an integrated ESCS system fails to add a new Pareto point over the best surviving fixed, recurrent,
  memory, and reactive controls after raw intake, idle work, event formation, dispatch, exploration, credit,
  retained byte-time, compaction, erasure, and control-plane overhead are counted;
- positives repeatedly disappear on fresh seeds, world families, referents, or independent verification;
- the only advantage is generated-world bookkeeping, hardware-specific sparse speed, or post-hoc metric
  selection;
- natural-referent confirmation fails after the structured-synthetic mechanisms are mature enough to test.

No kill criterion authorizes a larger model or more compute by default. A killed premise is retired or
replaced by one explicitly different premise.

## 18. Decision sequence

1. Finish P5 and run its independent verifier. Use its result to choose context controls only.
2. Mutation-test the four-event lifecycle, bounded archive, and exact accounting boundary. This is mechanics,
   not a result and does not bypass the governor chain.
3. Run EDCM-1 after the heavy lane clears.
4. If the EDCM complementarity gate fails, repair or retire the bed before reasoning about dispatch.
5. Run Experiment 0 independently to test the charged raw-event and idle boundary.
6. If EDCM complementarity is valid, run Experiment 1 with bounded dispatch, interaction credit, discovery,
   population scaling, and queue controls. A fixed-sentinel null licenses this one learned-credit premise
   change, not an open-ended router search.
7. Run Experiment 2 using the P6 lifecycle and P7 branch plane. A charged event former is required for a
   capability or efficiency claim; oracle-header results remain mechanics-only.
8. Freeze and implement `G0` before Experiment 3. Without it, narrow the study to scope allocation, merge,
   pruning, and repair within fixed actor families. Run it only if Experiment 1 or 2 survives.
9. Build an integrated ESCS only after Experiment 0 and at least two core premises survive separately.
10. Re-run the integrated winner against all component winners, fixed controls, fresh world families, and
    lifecycle accounting that includes raw intake, idle work, event formation, exploration, credit, retained
    byte-time, compaction, erasure, and the control plane.
11. Promote only natural, session-disjoint, independently verified effects. Preserve every null at its exact
    scope.

Operationally, this research sequence does not override the existing governor dependency chain. P5
verification and the admitted P6 progressive ladder remain receipt-governed. New heavy tasks require their
own preregistered policy declarations before execution.

## 19. Interpretation limit

A favorable ESCS experiment would show a bounded computational organization that produces more held-out
decision value per measured unit of work on a specified environment family. It would not establish general
intelligence, consciousness, biological equivalence, understanding, or moral status. Those claims remain
outside this document's evidence class.
